# Echosoul | Digital Time-Capsule & Will Vault
منصة آمنة ومبتكرة لحفظ الإرث الرقمي، الذكريات، والوصايا، مع إمكانية جدولتها زمنياً (مثل عام 2030) أو تأمينها عبر بروتوكول الأوصياء.

## 🚀 الميزات الرئيسية:
- **خزينة زمنية متقدمة:** قفل المحتوى حتى تاريخ مستقبلي محدد.
- **دعم الوسائط المتعددة:** رفع وصفظ الصور، المقاطع الصوتية، وفيديوهات الذاكرة مباشرة.
- **بروتوكول الأوصياء:** تفويض أشخاص موثوقين لتأكيد الإفراج عن الملفات الخاصة بعد الوفاة.
- **خصوصية مطلقة:** تخزين محلي آمن بالكامل على المتصفح دون الحاجة لقواعد بيانات معقدة.
